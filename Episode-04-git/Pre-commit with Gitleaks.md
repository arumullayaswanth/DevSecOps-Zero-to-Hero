
# 🖥️ STEP 7 — Pre-commit Framework with Gitleaks

#### Install pre-commit

* 🐧 [Linux](https://pre-commit.com/#install)
* 🪟 Windows (PowerShell):

```powershell
# Install using pip
python -m pip install pre-commit

# Verify installation
pre-commit --version

# Install pre-commit hooks in your repo
pre-commit install
```
* 🍎 macOS:

  ```bash
  brew install pre-commit
  ```
